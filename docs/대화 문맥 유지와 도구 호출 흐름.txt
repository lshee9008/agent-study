대화 문맥 유지와 도구 호출 흐름
1. 메시지 히스토리
    - 대화의 사용자 입력과 AI 응답을 순서대로 저장한 목록
    - 모델에 히스토리를 함께 보내면 이전 대화 내용을 참고할 수 있다.

2. 히스토리는 한 번만 초기화
    - messages = [] 를 대화 반복문 바깥에서 만든다.
    - 반복문 안에서 새 목록을 만들면 매번 이전 대화가 사라진다.

3. 사용자 메시지 추가
    - 입력을 받을 때마다 HumanMessage 를 히스토리에 추가한다.
    - messages.append(HumanMessage(content=user_message))

4. 모델 호출
    - 현재 입력만 보내는 대신 전체 메시지 목록을 모델에 전달한다.
    - model_with_tools.invoke(messages)

5. 모델 호출
    - 현재 입력만 보내는 대신 전체 메시지 목록을 모델에 전달한다.
    - model_with_tools.invoke(messages)

6. 도구 호출은 3단계
    - 요청: 모델이 도구 이름과 인자를 담은 AIMEssage를 반환한다.
    - 실행: 프로그램이 요청에 해당하는 Python 함수를 실행한다.
    - 결과 전달: 도구 결과를 ToolMessage로 히스토리에 추가하고 모델을 다시 호출한다.

7. 도구 요청과 결과를 함께 보냄
    - 도구 호출이 담긴 AI 메시지와 도구 결과를 모두 히스토리에 남긴다.
    - 그래야 모델이 어떤 도구를 요청했고 어떤 결과를 받았는지 연결해 이해한다.
